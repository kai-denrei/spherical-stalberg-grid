## A. Weathered-metal material (phase 1b)

**Verdict: `src/cine/materials.js` exports one pure baker + one thin three.js wrapper, applied by MATERIAL NAME across ring, tank, and containers — no SimplexNoise vendored, hand-rolled value-noise on mulberry32 instead.**

Contract:
- `bakeWeatheredMetal({ seed, size, baseHex, patinaHex, metalness:[lo,hi], roughness:[lo,hi] }) → { albedo: Uint8ClampedArray(size*size*3), orm: Uint8ClampedArray(size*size*3), normal: Uint8ClampedArray(size*size*3) }`. Pure, Node-testable, no three.js import. `orm` packs AO(R)/roughness(G)/metalness(B) — glTF's own convention — so it's one texture, not three.
- `makeWeatheredTextures(renderer, baked) → { map, ormMap, normalMap }` — thin effectful wrapper, three `THREE.DataTexture`s.
- `applyWeatheredMaterial(root, textures)` — walks any mesh tree for materials named `M_Armour`/`M_Steel`/`M_Detail`/`M_Turret`/`M_Rubber` (the contract `units.js` already uses at lines 1391–1901 for the container, the crane structure, and the tank/ring) and assigns the maps. **This is the one-baker-three-assets answer**: bake once per resolution, apply by name, no per-asset copy.

Noise: hand-rolled 3-octave bilinear value-noise seeded from `params.seed` via the existing `mulberry32` stream (`src/rng.js`) — no SimplexNoise addon. It's in-idiom (every other seeded field in this repo is mulberry32), Node-testable, and weathering doesn't need simplex's isotropy. This spends zero vendor budget, banked for D below.

Resolution: **cinema tier 1024², game tier: none — the board stays flat-shaded.** Phone tier (`perftier.js`) already turns off MSAA and halves bloom; adding three DataTextures per material to every enemy-adjacent surface is not this session's job and isn't asked for. `applyWeatheredMaterial` exists so the game *can* adopt it later at a smaller size, unforced.

PBR numbers, extending `gate.js`'s existing `CINE_METAL` table (not replacing it — the baker modulates it):
- Base: `M_Armour` 0x3d4247, `M_Steel` 0x35393d, dark cool gunmetal, luma < 0.20.
- Metalness: 0.85–0.95 on raw plate, dropping to 0.10–0.30 inside the noise-masked patina patches.
- Roughness: 0.20–0.30 in cavity/recess mask, 0.55–0.80 on exposed edges (curvature-driven via a second noise channel, not a real AO bake).
- **Patina: teal-verdigris, not violet, not rust.** Rust-orange is `ALARM_HUES.orange` (the drifter enemy's own belt); violet is `ALARM_HUES.purple`/`purpleDeep` (barbed, prime) *and* already the wormhole throat's ambient light in `gate.js` — either would make weathered player hardware misread as a threat colour or steal the throat's own accent. Teal (`~0x0d1c1a` tint, luma ≤ 0.15, the same dark-cluster rule `enemyspec.js` uses to keep the phantom's accent legible) sits next to nothing in either belt palette and echoes the tron/CRT cyan already on the ring's glow strips (`0x8fd4ff`).
